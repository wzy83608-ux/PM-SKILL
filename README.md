## 下载与使用

1. 点击顶部“下载完整技能库”，解压后打开 `skills` 目录。
2. 将所需的完整 Skill 文件夹复制到本机 Codex 的 `skills` 目录。
3. 阅读对应 `SKILL.md`，按要求配置依赖和自己的服务账号。

Skill 保留原目录名称及同级结构；广告系列建议将 `ads` 与所需 `ads-*` 一起安装。仓库包含脚本、模板和参考资料。Codex内置技能及插件由其安装机制维护，不包含在本库中。
